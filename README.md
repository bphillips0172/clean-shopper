# Clean Shopper

An AI-powered assistant for discovering clean, non-toxic, and environmentally friendly home and pantry products: research products, compare them on ingredient safety and sustainability, save preferences, and build a shopping list.

Demo project for **Claude Code for Designers**. See [`docs/CCDCourse_CleanShopper_ProjectBrief.md`](docs/CCDCourse_CleanShopper_ProjectBrief.md) for the full brief.

## Getting started

```bash
npm install
npm run dev
```

Built with React and Vite.
